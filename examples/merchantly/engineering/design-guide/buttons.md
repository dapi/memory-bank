# Merchantly Buttons

Use existing project action hierarchy and component conventions before adding new button styles.

## Rules

- Primary actions should be visually distinct and limited to the main action on a surface.
- Destructive actions require explicit labeling and safe placement.
- Secondary actions should not compete with the primary action.
