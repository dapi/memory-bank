# Merchantly Frontend Engineering

Merchantly frontend rules extend the template-level [`../../../memory-bank/engineering/frontend.md`](../../../memory-bank/engineering/frontend.md). Use this document as the project-specific entrypoint when a feature changes customer-facing pages, operator UI or shared UI conventions.

## UI Surfaces

- customer-facing public order and payment result pages;
- operator panel;
- embedded or provider-adjacent payment flows where Merchantly owns the final render surface.
