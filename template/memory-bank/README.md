# Memory Bank

Memory Bank хранит проектную документацию и выбранные правила её сопровождения.
DNA применима самостоятельно. Documents добавляет типы и базовые шаблоны; Flows
подключает процессы. Конкретный документ получает flow gates только через explicit adoption.
Индекс ниже генерируется по установленному составу. Текст вне managed block принадлежит проекту.
