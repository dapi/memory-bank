# PRD Validation

Это опциональный процесс поверх [базового контракта](../document-types/prd.md).
Подключение выполняется явно через prd/v1 из [каталога](contracts/README.md).

Уточни goals, scope и проверяемые requirements в базовом PRD.
В секции Validation зафиксируй проверку требований с их источниками и критериями
успеха. Изменения требований обновляют canonical PRD, а не создают второй owner.
