# Context Priming Profiles

Этот каталог разделяет общий priming contract и route-specific profiles.
Сначала прочитай contract для P0; после Task Routing открой только профиль
выбранного route и его exact input manifest.

- [Context Priming Contract](context-priming.md) — P0/P1/P2 model, schema
  exact input manifest и ownership границы.
- [P1-INC: Incident](incident.md) — timeboxed inputs для triage и containment.
- [P1-BUG: Bug Fix](bug-fix.md) — expected/actual behavior, reproduction и
  regression inputs.
- [P1-RES: Research](research.md) — decision question, evidence и stopping
  condition до bootstrap.
- [P1-SMALL: Small Change](small-change.md) — reference pattern и local verify
  surface для fast path.
- [P1-REF: Refactoring](refactoring.md) — preservation boundary, baseline и
  characterization coverage.
- [P1-EPIC: Epic](epic.md) — intake facts, candidate slices и open questions.
- [P1-FEAT: Feature](feature.md) — problem-space upstream and local inputs.
- [P1-HUMAN: Human Routing](human-routing.md) — competing routes и точный
  вопрос для human gate.
