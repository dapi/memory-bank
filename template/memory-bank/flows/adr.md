# ADR Review

Это опциональный процесс поверх [базового контракта](../document-types/adr.md).
Подключение выполняется явно через adr/v1 из [каталога](contracts/README.md).

Подготовь контекст и варианты; запиши предлагаемое решение в базовом ADR.
В секции Review зафиксируй проверку последствий и основание для принятия решения.
Публикационный status не подменяет decision_status. Принятие или замена решения
должны иметь evidence и соответствовать полномочиям проекта.
